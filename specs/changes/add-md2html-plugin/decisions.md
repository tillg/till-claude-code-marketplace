## 2. Implementation decisions

(appended during implementation)
- **D1 Prose colons in lint.** `remark-directive` parses `16:00` as text directive `:00` and `a:b` as `:b`. An unknown *inline* directive with no `[label]` and no `{attrs}` is treated as prose: rendered literally, **no** lint message. Unknown container/leaf directives, and unknown inline ones with a label or attrs, are errors.
- **D2 Card title** is plain text (not inline Markdown).
- **D3 Assets.** `src/assets.mjs` reads `base.css` and the version from `package.json` at runtime in `src/`; the bundle script swaps it for inlined strings, so `dist/` needs no sibling files.
- **D4 Class `mmd-src`** on the figure's source link, and token `--figure-bg` (reference hard-codes `#fff` so SVG diagrams stay legible in dark mode) were added to the contract.
- **D5 Pinned versions**: unified 11.0.5, remark-parse 11.0.0, remark-gfm 4.0.1, remark-frontmatter 5.0.0, yaml 2.9.1, remark-directive 4.0.0, remark-stringify 11.0.0, remark-rehype 11.1.2, rehype-stringify 10.0.1, unified-lint-rule 3.0.1, unist-util-visit 5.1.0, esbuild 0.28.2.
- **D6 `check`** runs all three stages (fmt --check, lint, build --check) and reports everything, instead of stopping at the first failing stage (`&&`). Exit code = worst stage.
- **D7 `new`** uses the *local* date (not UTC), creates parent dirs, refuses non-`.md` paths, and works without `reports.json` (setup may not have run yet).
- **D8 Source discovery** walks the project root, skipping dot-dirs, `node_modules` and `.worktrees`; results sorted by path.
- **D9 Bundle** is built with `absWorkingDir` = plugin root and `legalComments: none`, so output does not depend on the cwd. `dist/md2html.mjs` exports the library API and runs the CLI only when it is `process.argv[1]`.
- **D10 Hook** resolves a relative `file_path` against the hook input's `cwd`; a broken `reports.json` exits 2 with the config error (Claude should see it); unreadable stdin exits 0.
- **D11 `--watch`** uses `fs.watch(root, {recursive: true})` with a 100 ms debounce; changes to `reports.json` or the theme rebuild all watched reports. Manual test only.
- **S1 Tool lookup** in skills: project `tools/md2html.mjs`, else `find ~/.claude/plugins/cache -path '*/md2html/*/dist/md2html.mjs' | sort -V | tail -1` (highest version dir), else any `~/.claude/plugins/**/md2html/dist/md2html.mjs` (marketplace checkout).
- **S2 `write` does not render Mermaid**: it tells Claude to render `.svg` from `.mmd` itself (e.g. `npx -y @mermaid-js/mermaid-cli`) and commit both; the build only links the `.mmd`.
- **S3 `build` serves on `127.0.0.1`** on a port picked by Python (`bind(0)`), checks it with `curl` before `open`, and leaves the server running in the background.
- **S4 `setup` theme stub** has every override commented out, so creating it changes no output; `theme` is set in `reports.json` only when the file exists. Defaults (`sources`, `lang`) are omitted from the written `reports.json`.
- **S5 `setup` CLAUDE.md pointer**: appends to an existing CLAUDE.md; asks before creating one. `.remarkrc.mjs` uses `export default preset` (assumes `preset` is a unified preset object).
- **S6 Root `CLAUDE.md`**: also added the missing `agent-bus` line under "Current Plugins" (it was in README and marketplace.json but not there).
- **L1 Heading ids for `#fragment` checks** come from build's `headingIds(source)` in `src/transforms/headings.mjs` (explicit ids reserved first, `section` fallback, invalid directives literalized, so `## At 16:00` → `at-1600`). A separate `lint/ids.mjs` was dropped: a copy would drift. Fragments are checked only for `.md` targets and same-file `#x`; other files only for existence.
- **L2 Links rule** also checks images and link definitions. Skipped: URLs with a scheme (`https:`, `mailto:` …), `//host`, and root-absolute `/x` paths. `?query` is ignored; paths and fragments are URI-decoded.
- **L3 Severities.** Errors: `directive-*`, `frontmatter`, `links`, `figure` (alt), `heading-id`, `menu` (CLI only, `reports.json` entries). Warnings: `figure` (`.svg` without `.mmd`, only when the `.svg` exists), `no-raw-html`, `callout-alias` (fmt fixes it and the content still renders as a blockquote), `theme-tokens`, `heading-number`. `figure` is two `unified-lint-rule` plugins with the same id, since a rule has one severity.
- **L4 Directive display names** use the canonical colons (`::::cards` for containers that hold directives, `:::x`, `::x`, `:x`); an unknown directive is shown as written (its own colons). Suggestions search all registry names regardless of form, so `::tldr` → `Did you mean ":::tldr"?`.
- **L5 D1 detail.** "No label" = the source slice has no `[` or `{` right after the name; `:x[]` (empty label) is an error.
- **L6 Extra messages beyond the table:** `"::::cards" may only contain ":::card"` (non-card child), `":::tldr" takes no attributes, found "x"`, `":::card" has unknown attribute "titel". Did you mean "title"?`, `":verdict" needs tone="…". Use go | partial | no`, frontmatter: missing/empty/non-mapping frontmatter, invalid YAML (first line of the `yaml` error, at its line), `"title"`/`subtitle`/`description` must be non-empty strings, impossible dates (`2026-02-30`) count as non-ISO.
- **L7 `directive-closed`** = the node's source slice does not end with a line of only colons (optionally after `>`/spaces) at least as long as the opening fence. "file ends at line N" = number of lines, ignoring the final newline.
- **L8 YAML** is parsed with `{ schema: 'core' }` (YAML 1.2), so dates stay the strings written; duplicate keys are a YAML error.
- **L9 `lint()` defaults** `readFile`/`exists` to the filesystem under `root`; the preset's rules default to paths relative to `file.path` (cwd-relative or absolute). `lint()` imports `VFile` from `vfile` (a dependency of `unified`, not listed in `package.json`).
- **L10 Preset** includes `remark-parse` and `remark-stringify` so `unified().use(preset).process()` works standalone; `settings` = `STRINGIFY_OPTIONS`.
- **L11 `formatMessages`** returns a string (lines joined by `\n`, no trailing newline; `''` when clean); JSON is a pretty-printed (2-space) array of `{file, line, column, severity, message, ruleId}` for one file — a multi-file CLI concatenates the arrays.
- **L12 `theme-tokens`** finds `--name:` declarations after comments and strings are blanked; `var(--x)` uses are not definitions. Suggests the nearest contract token (Levenshtein ≤ 2). The token list lives in `src/lint/theme.mjs` (`CONTRACT_TOKENS`).
- **F1 Text is re-emitted from source.** `fmt` writes every text node (and every autolink, bare or `<…>`) as its exact source slice, with only the container prefixes (`> `, list indent) of continuation lines re-derived. Authors' escapes are neither added nor removed (`2 * 3`, `[x]`, `a_b_c`, `\*` all stay). Safety net: the output is re-parsed and must give the same mdast (positions ignored); if not, the whole document falls back to plain `remark-stringify` escaping. Both paths are idempotent. *(Fallback superseded by F8.)*
- **F2 Invalid directives are verbatim.** Unknown directives (incl. prose colons `16:00`, `:443`, `a:b`), directives with attr problems, and nesting violations (`card` outside `cards`, non-card inside `cards`) are written byte-for-byte, because `build` renders them as literal source. A container holding such a container is verbatim too (its fence length would otherwise be wrong).
- **F3 Colon counts** come from `mdast-util-directive`'s `fence()` (verified: `:::card` alone = 3, `::::cards` with cards = 4, `:::tldr` = 3). `:::cards` with a 3-colon `:::card` inside is not fixable: the first bare `:::` closes `cards`, so the second is prose and stays (`colon-three-on-cards` fixture); lint's job. *(Superseded by F14.)*
- **F4 Attributes** are reordered to registry key order and double-quoted. With today's registry (one attr per directive, unknown attr = invalid = verbatim, F2) this reduces to quoting.
- **F5 Frontmatter** goes through `yaml`'s Document API: keys in schema order, then unknown keys in original order; quoted string scalars become plain where YAML allows (`yaml` still quotes when needed, e.g. `"a: b"`); `lineWidth: 0` (no folding). Comments are kept and travel with the key they precede. If the YAML doesn't parse, isn't a map, or the rewrite doesn't parse back to deep-equal data, the frontmatter is left byte-for-byte untouched.
- **F6 `> [!tldr]` callouts** (any case, first line of the blockquote) become `:::tldr` holding the rest of the blockquote. A trailing title (`> [!tldr] Short answer`) is **kept** as the first line of the first paragraph, not dropped (no data loss). Fold markers (`[!tldr]-`) are not recognised. Other callouts stay blockquotes.
- **F7 Library defaults kept as canonical**: tables get `| :- | -: |` delimiter rows *(superseded by F9)*, `***` → `---`, `1)` → `1.`, hard breaks → `\`, setext → ATX headings, continuation-line leading spaces dropped (same HTML). Output is LF, NFC, exactly one final newline (empty input → `"\n"`).
- **F8 Per-block fallback, never a different tree.** `fmt` verifies each top-level block of the re-parse against the normalised tree. The first block that differs is upgraded RAW (source-slice text, F1) → ESCAPED (`remark-stringify`'s own escaping, that block only) → SOURCE (the block's original bytes, compared against the un-normalised block); if the difference sits in a SOURCE block, the block before it is upgraded; if nothing is left, the whole input is returned unchanged. So one bad block (e.g. a ragged table `| a |` / `| b | c |`, which the library would widen) no longer re-escapes the rest of the document (`[x]`, `2 * 3`, `> [!NOTE]`, `~50`, `:thumbsup:`, `&lt;`, bare URLs all stay as written), and a leading `***` stays `***` when `---` would open frontmatter with a later `---`. Corpus check: 2000 `*.md` files under `~/git` (no `node_modules`/`.git`) all keep their mdast (positions ignored, frontmatter compared as data; the one file with a `> [!tldr]` excluded from the tree check) and are idempotent.
- **F9 Table delimiter cells are `---`, `:---`, `---:`, `:---:`** (remark-gfm's table handler wrapped; still `tablePipeAlign: false`, no padding to column width). The goldens `tables`, `canonical`, `prose-colons` and the preset stringify test encoded the library's `| - |`/`:-`/`-:` and were updated.
- **F10 Multi-line YAML scalars keep their lines.** `lineWidth: 0` would join a folded (`>-`) or multi-line plain/quoted scalar into one line, so frontmatter holding any scalar whose source spans lines is left byte-for-byte (no key reorder, no unquoting).
- **F11 The editor preset formats with `fmt`.** `preset` keeps the parse plugins and every lint rule but replaces `remark-stringify` by a compiler that returns `format(String(file.value))`, so format-on-save equals `md2html fmt` (frontmatter order, callout conversion, F1 escapes). The tree is only linted; tree transforms by other plugins in a user's `.remarkrc` would be ignored by the compiler. Fold markers (`[!tldr]-`/`[!tldr]+`) are now really left alone, as F6 says (the regex used to accept them).
- **F12 fmt never throws.** `formatYaml` catches everything (an unresolved alias such as `subtitle: *Draft*` throws in `toString()`) and also bails on `yaml` warnings: bad frontmatter stays byte-for-byte. `format()` itself wraps the whole pipeline; on any exception it returns the input (LF, NFC, one final newline) unchanged.
- **F13 Unclosed containers and duplicate attributes are verbatim** (like F2). A container whose source slice fails lint's L7 closing-fence test is written as-is instead of getting a `:::` appended at EOF (which silently swallowed the following sections), so `directive-closed` still fires; trailing blank lines of its slice are dropped (they grew by two per run inside list items). A directive whose `{…}` source repeats a key (`{tone="go" tone="no"}`; mdast keeps the last) is verbatim; the check is conservative (a `key=` in a label may over-report, costing only formatting).
- **F14 A container whose fence is not longer than a nested container's is verbatim** (supersedes F3's lock-in): with `:::cards` holding `:::card`, the card's `:::` closes the cards; fmt used to rewrite it to `::::cards` around the first card and leave the rest literal. Now the whole broken structure stays as written (1 or 2 cards), and a verbatim directive keeps its source line spacing to its neighbours (no blank line inserted before the stray `:::`/`:::card`), so lint's `"::::cards" needs four colons` still applies. Golden `colon-three-on-cards.out.md` encoded the old rewrite and now equals its input.
- **F15 Callout marker skipped in the source, not the value.** `> [!tldr]\t` has the tab in the source but not in the text value, so the raw slice started one byte early (a blank first line, settled only on the 2nd run). The skip is now matched on the source (marker, trailing blanks, newline, next line's `>`/indent). SOURCE-fallback blocks drop trailing blank lines too. Known limit: blank lines before EOF can make a list item holding an unclosed container `spread` (loose list); fmt's single final newline (F7) removes them, so tree/HTML equality is against the input with that ending. Fuzz test `test/fmt-fuzz.test.mjs` (6528 combinations: directives closed/unclosed/short-fenced/duplicate-attr in list items and blockquotes, callouts with trailing tabs/spaces, CRLF, EOF endings) asserts idempotence, tree equality (callouts aside) and `build` equality.
- **F16 Image alt source kept.** mdast keeps only the alt's plain text (`![a *b*](x.png)` → alt `a b`), so in RAW blocks `image`/`imageReference` nodes are written as their source slice.
- **F17 `yaml` runs with `logLevel: 'error'`** in fmt (`parseDocument` and both `parse` calls), so `Keys with collection values…` and other `YAMLWarning`s never reach stderr.
- **B1 Invalid nesting.** A non-`card` child of `::::cards` becomes literal on its own (the `cards` grid is kept); a `card` outside `cards` becomes literal as a whole block. Literal flow-level blocks (containers, leaf directives, block HTML) are wrapped in `<p>`.
- **B2 TL;DR hoisting** takes the first valid **top-level** `:::tldr` only (not one nested inside a card or list). Heading ids and section numbers are assigned before hoisting, i.e. in source order.
- **B3 Heading ids.** Explicit `{#id}` values are reserved first, then slugs are deduped around them (so `### Reco` after `{#reco}` gets `reco-1`); an empty slug becomes `section`. Numbering and the TOC count every `##` at any depth; TOC labels are plain text.
- **B4 Missing frontmatter keys** are omitted rather than invented: no `title` → the file name minus `.md`; missing `created`/`edited`/`status` → that `report-meta` row is left out; bad YAML → rendered as if there were no frontmatter. Parsed with `yaml` `{schema: 'core'}`, so dates stay strings.
- **B5 Figures.** An image-only paragraph with empty alt text gets no caption text, only the `source` link when a `.mmd` exists. The `.mmd` lookup swaps any extension, resolves against the report dir, and never goes outside the root.
- **B6 Figure background.** `--figure-bg` (#fff) is applied to the `<img>`, and the figure frame uses `--card`, so `figcaption` in `var(--muted)` stays legible in dark mode (caption on white was ~2.5:1).
- **B7 Extra base.css rules** outside the contract, needed for GFM output: `pre`, `blockquote`, `hr` (+ `hr + h2` drops the doubled rule), `th/td[align]` (the reference's `text-align: left` overrode GFM column alignment), `.contains-task-list`, `.footnotes`, `.sr-only` (remark-rehype's footnote label). `.small` was dropped (A9).
- **B8 Theme CSS** is inserted verbatim into `@layer theme { … }` (the block is always present, even if empty); `</style` is escaped in both base and theme CSS.
- **B9 `> [!tldr]` renders as `:::tldr`** (`src/transforms/callouts.mjs`, run before directive validation): any case, first line of a blockquote, at any depth, no fold marker (`[!tldr]-`/`[!tldr]+` stay blockquotes). A trailing title stays as the first line of the first paragraph (as F6), and the first top-level one is hoisted (B2), so `build(x) === build(fmt(x))`. L3's note that a callout "still renders as a blockquote" no longer holds; `callout-alias` remains a warning for canonical style.
- **B10 `relHref` is pure string arithmetic** (no `path.posix.relative`, which resolved against `process.cwd()`). URLs with a scheme, `//host` and root-absolute `/x` pass through unchanged (no `normalize`, no `.md` → `.html`), for `brand.icon` and `reports[].path` alike. Tested by building from two cwds (`determinism.test.mjs`).
- **B11 Unsafe URLs are dropped, not rewritten.** `<a>` whose href is `javascript:`, `vbscript:` or `data:` (after removing ASCII whitespace/control characters, as browsers do) is replaced by its content; `<img>` whose src is `javascript:`/`vbscript:` becomes its alt text (nothing if empty). `data:` images are kept. Applies to body and subtitle, before the figure rule, so a dropped image never becomes a `<figure>`.
- **B12 Theme CSS is normalised** like report input (CRLF/CR → LF, NFC) before inlining, so the page does not depend on the theme file's line endings or Unicode form.
- **B13 Menu `#fragment`/`?query`** is split off before `.md` → `.html` and appended to the relative href (`specs/a-report.md#top` → `a-report.html#top`); `aria-current` compares the path part only. External entries are never current.
- **B14 Subtitle gets no figure transform**: an image-only subtitle is a plain inline `<img>` inside `<p class="sub">` (was `<img><figcaption>` inside a `<p>`). Images keep `max-width: 100%`, so an SVG without intrinsic size fills the width there as it does in body text.
- **B15 Pills and current nav item follow the tokens.** `.report-status.research` = `var(--accent)` on `color-mix(in srgb, var(--accent) 14%, transparent)`, `ongoing` = `--partial`/`--partial-bg`, `implemented` = `--go`/`--go-bg`; the current nav item's text is `var(--bg)` on `var(--accent)`. The per-scheme hard-coded overrides are gone, so a theme that sets the tokens restyles both. Goldens were regenerated for this: the old ones encoded the hard-coded colours (CSS-only diff, bodies unchanged).
- **B16 Right-aligned cells** (`th/td[align="right"]`) get `white-space: nowrap; font-variant-numeric: tabular-nums` (the reference's `td.num`); `.tbl` scrolls horizontally, so the page still does not scroll at 390 px.
- **B17 Literal text drops container prefixes.** An invalid/unknown directive inside a blockquote or list item renders as the source the author wrote *inside* the container: on every line after the first, each ancestor's prefix is removed, outermost first (`>` plus one optional space for a blockquote, up to the item's content indent for a list item, up to 4 spaces for a footnote). Lazy lines without the prefix are kept as is. So `> :::tldr{x=1}` / `> body` / `> :::` → `<blockquote><p>:::tldr{x=1}\nbody\n:::</p>`, `> - :::unknown` likewise; raw HTML already had no prefixes (`node.value`).
- **B18 Literal text ignores trailing blank lines.** Trailing spaces/tabs/newlines are cut from the literal slice, so an unclosed invalid container at EOF (whose node runs to the end of input) builds the same with or without a final newline.
- **B19 BOM.** `normalizeInput` strips a leading U+FEFF (processor, owned by fmt); build slices only `normalizeInput`'s output (body, subtitle, theme CSS), so `\uFEFFIt is 10:30.` keeps `10:30` and a theme starting with a BOM keeps its first rule. Covered by `test/build-round2.test.mjs`.
- **B20 Frontmatter YAML** is parsed with `{schema: 'core', logLevel: 'error'}`: unresolved tags etc. print no `YAMLWarning` to stderr; an unresolved alias (`subtitle: *Draft*`) throws inside `yaml` and is caught, so the page renders as if the frontmatter were invalid (B4).
- **B21 Subtitle images are text-height.** `.sub img { height: 1.2em; width: auto; vertical-align: middle; }` (supersedes B14's "fills the width"): an image without intrinsic size no longer spans the subtitle. Goldens regenerated for this one CSS line (bodies unchanged).
- **D12 Bundle require shim.** `yaml` resolves to its CommonJS build under esbuild, which fails in an ESM bundle ("Dynamic require of process"). The bundle banner defines `require` via `createRequire(import.meta.url)`.
- **D13 `vfile`** (used directly by `src/lint.mjs`) pinned explicitly as a devDependency at the version already in the tree.
- **D14 Review fixes (CLI/config).** Explicit non-`.md` paths exit 2 ("not a Markdown report") for fmt/lint/build (was: `build notes.txt` overwrote the file). Directory arguments expand to the sources inside them. Paths are compared after `realpath` (macOS `/tmp` → `/private/tmp`). `reports.json` rejects absolute paths in `sources`, `reports[].path`, `brand.icon`, `theme`; URLs are allowed for `reports[].path` and `brand.icon` only. `lint <paths>` no longer lints the theme (only `lint` over all sources and `check` do).
- **D15 `new`** quotes the title whenever YAML's core schema would not read it back as the same string (`null`, `true`, `2024`, `- x`, `? x`, `#x`, `a: b`, multi-line), and writes the skeleton through `format`, so it is canonical by construction.
- **D16 Hook scope** equals `check`'s: files under dot-dirs or `node_modules` are skipped even if they match `sources`.
- **D17 Cheat-sheet snippet** for `:verdict` now uses the canonical quoted form `{tone="go"}`.
- **L13 `:::cards` with a short fence** (P3) is reported by `directive-nesting` (error) at the opener: `"::::cards" needs four colons when it holds cards (found ":::cards")`. Trigger: a known container that holds directives, opened with < 4 colons, with a card child. Suppressed as consequences: `directive-closed` for its child cards, and `must be inside` for cards that follow it in the same parent (they spilled out).
- **L14 `heading-number`** *(rule superseded by L25)* (warning, new rule id): a `##` (depth 2 only) whose first text starts with `1.`, `1)`, `2.3`, `2.3.` + whitespace. `2024 results`, `3.x` and `###` headings are not flagged.
- **L15 `heading-id`** (error, new rule id): duplicate explicit `{#id}` within one file, at the later heading. The `{#id}` regex is a copy of `ID_SUFFIX` in `transforms/headings.mjs` (not exported; lint may not edit transforms). Slug collisions are not flagged (build de-duplicates them).
- **L16 `.html#frag` links** (P6): when the sibling `.md` exists (no `sources` match needed), the link counts as a report link: existence is satisfied by the `.md` (the `.html` may be unbuilt) and the fragment is checked against the `.md`'s ids. Without a sibling `.md`, the `.html` must exist; no fragment check.
- **L17 Digit-named inline directives** (M3): an unknown text directive whose name starts with a digit and has a label/attrs (`10:30[^1]`, `3:1[x]`, `9:05{x=1}`) gets `":30[…]" is read as a directive; write "10\:30[^1]" (escape the colon) to keep the time or ratio` (`directive-known`, error) instead of `unknown directive`. The fix quotes the source slice with the preceding `[\w.]*` run. D1 prose (`16:00`, `:443`, `a:b`) is unchanged.
- **L18 Unsafe URL schemes** (M5, `links`, error): `unsafe URL scheme "javascript:"`. Links and definitions: `javascript:`, `vbscript:`, `data:`; images: `javascript:`, `vbscript:` (`data:` images allowed). Whitespace/control chars are stripped and case folded before matching. Definitions are treated as links even when only an image reference uses them.
- **L19 Subtitle links**: the frontmatter `subtitle` is parsed as Markdown and its links/images get the same checks (existence, fragments, schemes). Position = subtitle line, value column + offset in the string (+1 for a quoted scalar; approximate for escapes or multi-line scalars). Skipped when the YAML is invalid (the `frontmatter` rule reports it).
- **L20 Duplicate attributes / container labels** (`directive-attrs`, error): `":verdict" has duplicate attribute "tone"` is found in the `{…}` source slice (after skipping a balanced `[label]`; `#id`/`.class` tokens ignored), since mdast keeps only the last. A registry container with a `[label]` (mdast `directiveLabel` paragraph) gets `":::tldr" takes no [label]`.
- **L21 YAML hint**: when the error line looks like `key: unquoted value with: colon`, the message becomes `frontmatter is not valid YAML: <first line of parser error> (line N). Quote values that contain ": ", e.g. <key>: "…"`. Other YAML errors are unchanged.
- **D18 Performance, accepted.** A 1 MB Markdown file takes ~5 s in plain `remark-parse` (upstream), so `fmt` (two parses) takes ~10 s. Real reports are 10–200 KB; not optimised.
- **D19 `callout-alias`** no longer fires on fold markers (`> [!tldr]-`), which fmt and build intentionally leave as blockquotes.
- **D20 Round-2 CLI fixes.** `lint` over all sources (and `check`) validates `reports.json` menu entries: a non-URL entry must exist (an `.html` entry is fine if its `.md` exists) — rule `menu`, error. `build --check`/`check` report **orphaned** generated HTML (has the md2html generator meta, sits where a `sources` report would be, `.md` gone). `build --watch` reloads config and the source list on every batch, and skips files deleted mid-batch. `new` warns (exit 0) when the path is outside `sources`.
- **D21 Hook lints before formatting.** If the file as Claude wrote it has lint errors, the hook exits 2 and does **not** rewrite it (fmt could otherwise hide an unclosed container by closing it at EOF). Only a lint-clean file is formatted. A directory named `*.md` is ignored.
- **D22 BOM.** `normalizeInput` strips a leading U+FEFF (micromark drops it, which shifted every source offset by one).
- **D23 Cheat sheet** frontmatter example quotes the subtitle (`" #"` starts a YAML comment); card snippets have placeholder text so the rendered cheat sheet is canonical.
- **L22 Shared lint cache.** `lint(source, { …, cache })`: `cache` is a `Map` from root-relative `.md` path to that report's fragment ids (`string[]`, or `null` if unreadable), filled lazily by `links`. Callers linting many reports of one root pass one `Map` to every call, so each target is read and parsed once (72 cross-linked synthetic reports: 59 s → 2.2 s). Default: a new `Map` per call. The file being linted is never stored (its ids come from the source passed in, which may differ from disk); entries are not invalidated, so a cache must not outlive edits.
- **L23 Orphaned `.html` links** (`links`, error): `x.html[#frag]` whose `x.md` does not exist but would match `config.sources` → `"x.html" is generated from "x.md", which does not exist`, whether or not a stale `x.html` exists. Without `config` (editor preset) the old rule applies (the `.html` must exist).
- **L24 Footnote ids.** An explicit `{#footnote-label}` is a `heading-id` error: `id "#footnote-label" is reserved for footnotes` (always, even in a report without footnotes yet). Fragment targets include the ids remark-rehype writes for footnotes — `footnote-label`, `user-content-fn-<label>`, `user-content-fnref-<label>` and `-2`, `-3` … for repeated references — taken from running `remark-rehype` on the target (only when it has a footnote reference), and checked against the built HTML in a test. Slug collisions with these ids (`## Footnote label`) are not flagged.
- **L25 `heading-number` rule** (replaces L14's regex). A section number is 1–2-digit components joined by `.` (`1`, `2.3`, `10.2`), not followed by another digit. Flagged on a `##` when it is followed by `.`/`)` and whitespace (`1. x`, `2) x`, `2.3. x`), or is dotted and followed by whitespace (`2.3 x`), or — without that — directly by an uppercase letter after optional whitespace (`1 Intro`, `1.Intro`, `4)Wrap`, `10.2.Deep`). Never flagged: a component of 3+ digits (`2024. Review`, `2024 results`, `1.234`), a later component that is `0` (read as a version: `2.0 Migration`, `1.0 Scope` — accepted miss), a bare number before lowercase (`3 options`), `3.x`. Accepted false positive: `## 5 Whys`.
- **L26 YAML alias/anchor values** (`frontmatter`, error): a known key whose value is an alias (`*x`) or carries an anchor (`&x`) → `"subtitle" starts with "*", which YAML reads as an alias; quote the value: subtitle: "*Draft*"` (`an anchor` for `&`), at the value; the suggestion is the rest of the line JSON-quoted. The key counts as present; its other checks are skipped. Alias values are never converted to JS (an unresolved alias throws there).
- **L27 YAML `logLevel: 'error'`** on every `parseDocument` in lint (frontmatter, subtitle links), so yaml never prints a `YAMLWarning` (test: child process, stderr empty).
- **L28 BOM** is stripped by `normalizeInput` (D22); every lint rule slices `file.value`, which `lint()` sets to the normalized text, and target files go through `headingIds`/`parse`, which normalize too. Test: BOM input lints exactly like without.
